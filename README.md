# Mon projet 

##  La Description
    Ce projet est un programme simple écrit en javascript. Il demande à celui qui va l'utiliserde pouvoir entrer un nombre dans la machine et ainsi ce nombre lui sera afficher sous forme de resultat.

## Les Différentes Fonctionnalitées
    - demander un nombre à l'utilisateur,
    - convertir la saisie en nombre,
    - stocker le nombre converti dans une variable,
    - fermer l'interface de saisie.

## Les technologies utilisées 

    - VisualStudioCode,
    - JavaScript,
    - Node.js.

## L'exécution du programme

    Il faut dans le terminal démarrer le programme avec node.js et l'ordinateur va ramener une question demandant d'entrer un nombre. Après cela il faut entrer le nombre voulu et valider.
